Algorithm Steps

1. Project both UAVs to t_anchor.
2. Compute VIP forward axis:
   vip_fwd = vel_vip / |vel_vip|
3. Compute relative vector:
   rel = pos_pleb − pos_vip
4. Project onto VIP forward:
   proj = dot(rel, vip_fwd)
5. If proj > 0 → ACCELERATE
    If proj ≤ 0 → BRAKE
